Campagnes › module 15, les actions marketing — proposition. Une action marketing est un objectif d'activités que le marketing donne aux délégués pour une campagne : « pendant la campagne, faites ce type d'activité N fois chacun ». Delorc compte tout seul ce qui est réalisé à partir des activités que chaque personne enregistre (module 8b). Les points à approuver sont en bas.

  1. Une action (décidé) : un type d'activité (Studio › Types d'activité), des dates dans celles de la campagne, un objectif par personne, des personnes, un budget (une seule fois pour l'action), une wilaya et des spécialités pour information. Proposé : la wilaya et un lieu libre (l'« adresse » de l'API précédente) sont facultatifs ; au moins une spécialité n'est pas obligatoire.
  2. Prévu = objectif × personnes (décidé : « 2 » = 2 chacun, comme les anciennes données). Réalisé (décidé) = les activités du type de l'action, enregistrées par une de ses personnes, datées dans les dates de l'action et déjà passées. Une activité de plusieurs jours compte pour 1.
  3. Proposé : une même personne ne peut pas avoir deux actions du même type dont les dates se chevauchent (refusé à l'enregistrement), pour qu'une activité ne compte jamais deux fois. Faire plus que l'objectif est permis (3 / 2 = 150 %).
  4. Les personnes (décidé) : les personnes de terrain des équipes de la campagne dont le rôle peut enregistrer ce type d'activité ; recherche avec puces, ou « + toute une équipe ». Proposé : une personne qui ne peut pas (autre rôle) est grisée avec la raison.
  5. Qui gère (décidé) : le marketing (campaigns.update), sans validation. Proposé : tout se change à tout moment (objectif, personnes, dates) : le réalisé se recalcule, rien n'est stocké ; supprimer une action est toujours possible (aucune donnée n'y est rattachée) ; une campagne avec des actions et un type d'activité utilisé par une action ne se suppriment plus.
  6. Qui voit (décidé) : le marketing et les admins tout ; un manager les personnes en dessous ; un délégué ses propres actions et sa progression.
  7. Écrans (décidé) : l'onglet « Actions marketing » de la campagne (frame 1), la page d'une action par personne (frame 3), et Engager › Actions marketing groupé par personne ou par type (frames 4–6). Les autres regroupements des anciennes applications (spécialité, équipe, région, wilaya) attendent le tableau de bord (21).
