Studio › Settings — Product categories and Competitor info types. Both become ordinary Settings lists (like Specialities or Expense types): a list with search, a side panel to read, edit or delete, “Add” in the same panel. Product categories leave the Studio tabs for a new Settings group Products setup. Rules to approve at the bottom.

Rules to approve

  1. Product categories move to Studio › Settings › Products setup; the Studio tab goes. decided
  2. A category used by pack discount tiers can't be deleted (the API answers 409, the panel says why). Today the database would delete the tiers with it. decidedExample: “Stratégique” has 3 tiers in 2 packs → Delete is refused until those tiers are changed or removed in Packs.
  3. “Calculate total” is not shown. The old apps never read it (checked in all labs), it stays in the database untouched; we decide on it with Packs. decided
  4. Competitor info types: the 5 kinds get clear names: Source → “Source”, Therapeutic → “Therapeutic class”, Action type → “Competitor action”, Argument → “Argument”, Support → “Material needed” (from the old report fields: origine, classe thérapeutique, type d'action, arguments, besoin de supports). decided
  5. A type used in reports can't be deleted (409), like other Settings lists. Today deleting it would quietly empty that choice in the reports. decidedExample: “Baisse de prix” is in 4 reports → Delete refused; rename it instead.
  6. API changes: only counts on the two lists (discount tiers + packs per category, reports per type) and the two delete guards. No column change.
