Professionals › Territories — proposal. Rule (docs/DECISIONS.md): places in one chain = any of them, most precise wins; different groups must all match; each rule type applies only to some kinds of professionals (speciality: doctors and dentists). Only types linked to professionals are offered. A territory is the part of the field one person works: the places it covers (regions, wilayas, communes, sub-zones) and optionally specialities, with for each wilaya Résidence / Semi-résidence / Hors résidence (used later by expenses). Territories can sit under a bigger one (e.g. “Centre” › “Alger Est”). People are assigned with a start and end date (one current territory per person, kept as history). List + tree, side panel for a quick look, full page for everything, 3-step add on its own page (it has too much for a panel). The technical “rule name” field disappears (it becomes the territory's name).
