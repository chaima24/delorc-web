Professionals › Rule types — proposal. Update: each type shows its link to professionals (how a professional reaches its items, and which kinds of professionals it applies to — e.g. Spécialité: doctors and dentists only). A type without a link (Segmentation) is not offered in territories. See docs/DECISIONS.md. Rule types are the building blocks of a territory: a territory says “these wilayas / communes / specialities / segments”. The list of types is set up by Delorc support (central console), so this page only reads — no add, no edit, no delete. Today it shows database tables and model classes; the new page explains instead how the types fit together, how many choices each one gives, and which territories use it. Placed before Territories in the menu.
