Commandes › partie 16a, les offres et les packs — proposition. Le laboratoire prépare ici ce qui servira aux bons de commande (16b) : les offres commerciales (une période et ses paliers de remise), les packs de commande (un panier tout prêt) et le seuil stratégique (onglet Réglages). Nouvel espace de menu « Commandes ». Les bons de commande arrivent en 16b. Les points à approuver sont en bas.

  1. Comme Produits (décidé le 18 nov.) : « Ajouter » ouvre le panneau à côté de la liste ; un clic sur une ligne ouvre le panneau en lecture (informations générales) ; « Ouvrir la page » mène à la page de l'offre ou du pack, où tout se modifie dans des cartes, sur place.
  2. Les paliers se saisissent dans l'offre (décidé le 18 nov.) : une carte « Paliers de remise » sur la page de l'offre, enregistrée d'un coup.
  3. Un palier = de, à, remise, remise réduite. La catégorie est supprimée (décidé le 18 nov.). « À » vide = « et plus », seulement sur le dernier palier.
  4. Deux remises par palier, saisies toutes les deux (décidé le 18 nov.) : la remise pleine quand la commande atteint le seuil stratégique, la remise réduite sinon. 0 = pas de remise.
  5. Contrôles des paliers (décidé le 18 nov.) : deux paliers ne se chevauchent pas ; chaque remise entre 0 et 100 ; un trou entre deux paliers est permis (pas de remise dans le trou).
  6. Quelle offre s'applique : les dates et l'interrupteur (décidé le 18 nov.) : l'offre active dont les dates contiennent la date de la commande. Deux offres actives ne peuvent pas avoir des dates qui se chevauchent.
  7. Objectifs de l'offre gardés, facultatifs (décidé le 18 nov.) : objectif budget, cible %, nombre de bons de commande. Rien ne les calcule encore.
  8. Une ligne de pack = produit, quantité, unités gratuites, « modifiable » (décidé le 18 nov.). Le prix est lu sur le produit au moment de la commande. « Modifiable » coché : le délégué peut monter la quantité, jamais descendre sous celle du pack ; non coché : quantité fixe. Les unités gratuites se choisissent parmi celles du produit (Studio › Produits).
  9. Un pack est fait pour un type d'acheteur (décidé le 18 nov.) : Pharmacie ou Grossiste (un distributeur compte comme grossiste).
  10. Seuil stratégique : un réglage du laboratoire, dans Commandes › Réglages (comme Coaching › Réglages), 50 % au départ (décidé le 18 nov.).
  11. Une fois utilisé, refusé (décidé le 18 nov.) : une offre ou un pack utilisé par une commande ne se supprime pas, il se désactive ; les paliers d'une offre utilisée ne changent plus. Avant 16b, rien n'est encore « utilisé ».
  12. Proposé : un laboratoire neuf commence vide (aucune offre, aucun pack), comme le coaching.
  13. Proposé : un produit n'apparaît qu'une fois dans un pack, et un pack a au moins une ligne.
  14. Droits (décidé le 18 nov.) : les admins, et le droit orders-setup (voir, ajouter, modifier, supprimer) que le laboratoire peut donner à un autre rôle. Les délégués ne voient les offres et les packs qu'en saisissant une commande (16b).
