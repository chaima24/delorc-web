Enquêtes, partie 19b-2 (répondre et lire les réponses), proposition. Le délégué répond dans le compte rendu de la visite ; les réponses partent avec le compte rendu. Le marketing et les responsables lisent les réponses dans un onglet « Réponses » et les exportent en Excel. Exemple : Karim (VM) visite Dr Yacine Belkacem le 11 déc. ; l'enquête « Qualification médecin — Cardiologie » (une fois par professionnel) lui est proposée, ainsi que « Suivi Cardiozen » (à chaque visite). Les points à approuver sont en bas.

  1. Décidé le 21 nov. : les réponses partent avec le compte rendu (comme les marques) et suivent son délai de correction ; une visite supprimée perd ses réponses, une visite annulée n'en a pas ; un responsable qui saisit pour un délégué répond pour lui. L'enquête est proposée si elle est ouverte, que le jour de la visite est dans sa période, que la personne y est active et que le professionnel est dans sa liste. On peut passer une enquête ; dès qu'une question a une réponse, les obligatoires doivent l'avoir. « Une fois par professionnel » : une seule réponse, sur la visite où elle a été donnée ; les visites suivantes la montrent en lecture, la correction se fait dans cette visite. Lecture : onglet « Réponses » + Excel ; les graphiques attendent les rapports.
  2. Proposé, à confirmer :
    • Place dans le compte rendu : un bloc par enquête proposée, après les marques, les ADV et le matériel, avant les personnes ; fermé, avec « Répondre ». Ouvert = commencé ; « Ne pas répondre » le referme et efface ce qui a été saisi ;
    • « À chaque visite » : le bloc revient vide à chaque visite ; « Reprendre les réponses du 3 déc. » remplit avec la dernière réponse de ce professionnel, à modifier ;
    • Contrôles par type : nombre ≥ 0 (décimales acceptées) ; pourcentage 0–100 ; un choix = une option ; plusieurs choix = au moins une ; « Autre, à préciser » demande son texte ; texte court 255 caractères, texte long 2 000. Une question non obligatoire peut rester vide. Les règles entre réponses viennent en 19c ;
    • Page de la visite : une carte par enquête répondue, modifiable sur place comme les autres cartes, par qui peut modifier la visite et tant qu'elle n'est pas verrouillée ;
    • Onglet « Réponses » : une ligne par professionnel répondu (« une fois ») ou par visite répondue (« à chaque visite ») : professionnel, personne, équipe, date de visite, questions répondues ; filtres personne, équipe, période ; un clic ouvre les réponses, avec un lien vers la visite. Même périmètre que les répondants : le marketing tout, un responsable ses personnes, un délégué les siennes (lecture) ;
    • Excel : une ligne par professionnel et visite, une colonne par question (Q1, Q2…, plusieurs choix séparés par « ; », « Autre : … »), plus personne, équipe, professionnel, type, spécialité, segment, wilaya, date de visite. Fait dans le navigateur, comme l'export existant, avec les filtres de l'onglet ;
    • Changement d'une question après réponses : impossible, l'enquête ouverte gèle ses questions (19a) ; une réponse garde donc toujours la question posée ;
    • Avancement : 19b-1 se remplit (répondus, réponses, cette semaine, « répondu le » dans les listes et dans « Mes enquêtes », qui gagne un lien vers la visite).
