Enquêtes, partie 19d-2 (appliquer un scénario aux cycles), proposition. Depuis le résultat d'un scénario, le marketing écrit le segment de chaque professionnel classé dans le cycle de son délégué ; les visites à faire suivent la grille de fréquences, comme un changement de segment fait à la main. Exemple : Sara applique « Aire thérapeutique » (2×2, 143 classés) le 22 nov. ; Karim a son cycle de novembre et déjà celui de décembre, Yasmine n'a pas de cycle en cours. Les points à approuver sont en bas.

  1. Décidé le 22 nov. : le marketing et les admins (surveys.update) appliquent ; tous les professionnels classés, après un aperçu ; les non classés ne sont jamais touchés ; on écrit dans le cycle en cours du délégué et dans ses cycles suivants déjà créés ; un professionnel absent du cycle n'est pas ajouté, il est listé pour son responsable, avec un export Excel ; les visites à faire suivent la grille de la personne.
  2. Proposé, à confirmer :
    • l'aperçu se compte par délégué + professionnel : « à changer » si au moins un de ses cycles change, « déjà juste » si tous ont déjà ce segment, « pas dans le cycle » s'il n'est dans aucun, « sans cycle » si le délégué n'a ni cycle en cours ni suivant ;
    • un professionnel dans le cycle de décembre mais pas dans celui de novembre : écrit en décembre, compté « à changer » ;
    • la liste « pas dans le cycle » est calculée dans l'aperçu, donc toujours à jour : on la rouvre et l'exporte quand on veut, sans rien stocker ;
    • appliquer à nouveau est permis à tout moment : on écrit le résultat du moment (nouvelles réponses, case changée) ; seules les lignes différentes changent ;
    • une ligne d'historique sur chaque cycle changé : « Segments du scénario Aire thérapeutique (Qualification médecin — Cardiologie) : 12 changés », et une sur l'enquête : « a appliqué le scénario … aux cycles : 38 changés » ;
    • la carte et le résultat montrent « Appliqué le 22 nov. par Sara Hamdi » (deux colonnes applied_at, applied_by sur survey_scenarios, dans sa migration de création) ;
    • un segment sans case dans la grille du délégué donne 0 visite à faire, comme aujourd'hui dans le cycle (« Pas de grille » déjà averti sur la page du cycle) ; un responsable peut toujours changer le segment à la main ensuite ;
    • un délégué en pause dans l'enquête compte quand même (ses réponses comptent déjà dans le résultat).
