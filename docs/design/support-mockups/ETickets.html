E-tickets (module 18), proposition. Un utilisateur du labo signale un problème de l'application depuis le bouton d'aide « ? » ; le support Delorc répond depuis la console centrale. Exemple : Karim (délégué, Demo Pharma) voit un écran noir quand il choisit le médecin ; il ouvre un ticket avec une capture, le support répond « Téléchargez la nouvelle version », Karim confirme que ça marche et ferme le ticket. Côté labo en français, côté console centrale en anglais (comme les autres maquettes centrales). Aujourd'hui : 20 nov. 2026. Les cadres pointillés orange sont à confirmer.

  1. Qui répond (décidé le 20 nov.) : le support Delorc, dans la console centrale. Les tickets sont enregistrés dans la base centrale, avec le labo, l'auteur (id et nom) ; un labo ne lit que les siens.
  2. Qui ouvre (décidé) : tout utilisateur du labo, quel que soit son rôle, depuis le bouton « ? » de la barre du haut, sur n'importe quel écran. Toujours actif, sans interrupteur de plan.
  3. Qui voit, dans le labo (décidé) : l'auteur et les personnes au-dessus de lui ; celles-ci lisent seulement. Seuls l'auteur et le support écrivent.
  4. Les états (décidé) : ouvert → en cours → résolu → fermé. Le support les fait avancer ; un ticket résolu est fermé par l'auteur ou le support ; l'auteur peut le rouvrir (retour à « ouvert »).
  5. Catégories, priorités, délais (décidé) : réglés une fois dans la console centrale, les mêmes pour tous les labos. Délai en heures d'horloge (week-end compris) ; « en retard » en rouge une fois passé, tant que le ticket n'est pas résolu.
  6. Messages (décidé) : une seule conversation, un message après l'autre. Fichiers (décidé) : photos, vidéos, PDF (jpg, png, webp, mp4, mov, webm, pdf), 20 Mo chacun, 5 par message.
  7. E-mails (décidé) : nouveau ticket et nouveau message du labo → l'adresse du support (réglage central) ; réponse ou changement d'état → l'auteur.
